## Usage

### Default Library (Core)

<Canvas of={IconStories.Default} />

```html
<orchestra-icon name="checked" fill="currentcolor" size="60px"></orchestra-icon>
```

### Informative Icons

Icons are decorative by default. Set `label` when a standalone icon conveys
information that is not already available as text.

<Canvas of={IconStories.Informative} />

```html
<orchestra-icon name="checkbox-check" label="Completed"></orchestra-icon>
```

A non-empty label exposes the host as a named image, discoverable with
`page.getByRole('img', { name: 'Completed' })`. Clearing the label restores
decorative mode. Keep icons inside named buttons decorative to avoid duplicate
announcements.

### Custom Library

<Canvas of={IconStories.CustomLibrary} />

#### With Hardcoded SVGs

To use a custom icon library with hardcoded SVGs, register it before rendering:

```typescript
import { registerIconLibrary } from '@orchestra-design-system/core'

registerIconLibrary('myIcons', {
  resolver: (name) => {
    const icons: Record<string, string> = {
      star: '<svg viewBox="0 0 24 24" xmlns="http://www.w3.org/2000/svg">...</svg>',
      heart:
        '<svg viewBox="0 0 24 24" xmlns="http://www.w3.org/2000/svg">...</svg>',
    }
    return icons[name] ?? ''
  },
})
```

#### From an External Package

For production use, import icons from an external package:

```typescript
import { registerIconLibrary } from '@orchestra-design-system/core'
import * as Icons from '@your-org/icons-library'

registerIconLibrary('externalIcons', {
  resolver: (name) => {
    const iconExport = (Icons as Record<string, any>)[name]
    return typeof iconExport === 'string' ? iconExport : ''
  },
})
```

Then use it:

```html
<orchestra-icon
  name="star"
  library="externalIcons"
  fill="red"
  size="24px"
></orchestra-icon>
```
